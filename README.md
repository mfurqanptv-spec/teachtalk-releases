# TeachTalk downloads

TeachTalk is an accessible teaching studio for TeamTalk servers: it
streams your PC audio or chosen applications together with your
microphone, plays other participants back with neural noise removal and
automatic level control, records lessons, and announces every action for
screen-reader users.

## Install

Download **TeachTalkSetup.exe** from
[the latest release](../../releases/latest) and run it. Windows 10
version 2004 or newer is required.

Once installed, TeachTalk updates itself: it checks here at startup and
offers any new version.

This repository holds the downloads and the update feed only. Built with
the TeamTalk 5 SDK by BearWare.dk.
